# Setup

Create a public repository named exactly `Gauravb741` under the GitHub account `Gauravb741`.

Copy the files from this package so `README.md` is at the root and every graphic is inside `assets/`.

```text
Gauravb741/
├── README.md
└── assets/
    ├── hero.svg
    ├── hero.gif
    ├── overview-graph.svg
    ├── fullstack-graph.svg
    ├── devops-graph.svg
    ├── cloud-graph.svg
    ├── ai-graph.svg
    ├── java-graph.svg
    └── stack-map.svg
```

Push:

```bash
git init
git branch -M main
git remote add origin https://github.com/Gauravb741/Gauravb741.git
git add .
git commit -m "Create graphical GitHub profile"
git push -u origin main
```
