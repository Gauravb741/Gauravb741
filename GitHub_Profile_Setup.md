- a working build/test path where applicable

## 6. Important note about the visual effects

The profile is designed for GitHub's Markdown/HTML environment. SVG animations are intentionally lightweight. GitHub can restrict or sanitize some advanced SVG behavior depending on how an asset is rendered, so the README remains useful even if a particular animation is reduced or not animated.
