## Selected projects

### [NITIGATI](https://github.com/Gauravb741/NITIGATI)

A two-sided services marketplace where providers list services and customers discover, message, and place orders.

**What it does:** Supports separate customer and provider roles, service listings with tags, media and credential uploads, order proposals (create, accept, reject, withdraw), dashboards for each role, and real-time chat between users. Providers can onboard by speaking instead of filling a form.

**Technical implementation:** Next.js (App Router), React and TypeScript on the front end with Tailwind CSS. Django REST Framework with token authentication on the back end, and Django Channels for WebSocket chat and onboarding. Voice onboarding transcribes audio with faster-whisper, extracts structured profile fields with the Gemini API, and replies with speech generated by Edge TTS.

**Why it is interesting:** The onboarding flow is a streaming pipeline (audio, transcript, LLM extraction, follow-up question, synthesized reply) over a single WebSocket protocol, rather than a simple form with an AI label.

[Repository](https://github.com/Gauravb741/NITIGATI)

### [CAPE](https://github.com/Gauravb741/CAPE)

An online examination platform for creating, scheduling, and taking multiple-choice tests.

**What it does:** Teachers create exams with questions, options, time windows, durations, and attempt limits. Students register for exams, attempt them, and see results. Dashboards show exam data and statistics.

**Technical implementation:** Astro with React islands, TypeScript, and Tailwind CSS on the front end, with chart components for analytics. Django REST Framework with token and session authentication on the back end, using SQLite. Webcam frames are sent from the browser to an endpoint that runs MediaPipe Face Mesh, and attempts store a counter for flagged behavior.

**Why it is interesting:** It treats exam integrity as an engineering problem, combining role-based flows, timed attempts, and computer-vision checks in one system.

[Repository](https://github.com/Gauravb741/CAPE)

### [Eye-tracking mouse and virtual keyboard](https://github.com/Gauravb741/Eye-tracking-mouse-and-virtual-keyboard-)

A hands-free way to control a computer with eye movement and hand gestures.

**What it does:** Moves the pointer by eye tracking, performs click, right-click, and double-click from hand gestures, and offers an on-screen keyboard operated by pinch gestures, with switching between mouse and keyboard modes.

**Technical implementation:** Python with OpenCV and MediaPipe for landmark detection, plus PyAutoGUI and pynput to drive system input.

**Why it is interesting:** It maps noisy camera landmarks to precise, usable input, which makes it a useful exercise in turning computer-vision output into reliable input for everyday software.

[Repository](https://github.com/Gauravb741/Eye-tracking-mouse-and-virtual-keyboard-)
